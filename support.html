Connecting

Open Hosts, tap Add host, then enter the address, user and port (22 by default). Choose a password or private key. The first connection asks you to trust the host key: check the fingerprint with your server administrator before accepting.

Mosh

Mosh needs mosh-server on the remote host. If it is missing, use SSH or install the mosh package. Mosh survives network changes but not app suspension or a kill.

Keys and errors

Passwords and keys are stored in the iOS Keychain or Android Keystore. Error banners have a Details action with the full message and a Copy button; send us that text if you need help.

Files and AI

Open a session and choose Files. Servers without SFTP fall back to shell commands. AI is optional and uses the endpoint and key you enter; no prompt is sent until you ask a question.

Pro and purchases

The app is free and sells a Pro tier: a one-time purchase or a yearly subscription. The price shown in the app comes from the store. Pro unlocks the server monitor, log tail, Git panel, port forwards and SOCKS5, the code editor, the AI assistant, jump hosts, the transfer queue, folders and tags, JSON backup and iCloud sync, unlimited hosts and snippets, and Android Local Linux.

If you reinstall or change device, open Settings → Lofi Shell Pro → Restore purchases and sign in with the store account you bought with. A yearly plan renews until you cancel it in your store account; you keep Pro until the period ends. Refunds are handled by the store.

New users can try Pro free for a week before the yearly plan starts. The trial is set by the store, so its length and the price after it are shown in the app when you open the Pro sheet; if you do nothing, the trial ends on its own and the yearly price begins then.

iCloud sync and the app lock

Both are off until you turn them on. iCloud sync needs this device signed into iCloud; the simulator, or a build whose profile lacks the iCloud entitlement, shows not available in this build. The app lock uses Face ID, Touch ID or the device passcode; if the device has no check set up, the switch refuses to turn on.

Backup

Settings → Backup & sync → Export and import writes your hosts, folders, snippets and settings as JSON. Passwords, keys and passphrases are never included.

Privacy

Lofi Shell has no account, no analytics and no backend of ours. Read the privacy policy.
