Lofi Shell

SSH + Mosh terminal for iOS and Android · local-first, no account

A quiet terminal for your servers: SSH and Mosh sessions that survive network changes, SFTP with a shell fallback, Git, a server monitor, log tail, port forwards, SOCKS5, tmux and an optional AI assistant that uses your own endpoint. Keys stay in the OS keychain. The download is free; a Pro tier adds the ops tooling.
